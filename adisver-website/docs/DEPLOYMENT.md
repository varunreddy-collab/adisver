# Deployment Notes

Use `index.html` as the website entry point.

The standalone Workshop page is `workshop.html`. The main Paushtika page also contains the integrated Workshop view and does not depend on the standalone Workshop CSS/JS.

Local navigation in the standalone Workshop page points back to sections of `index.html` so there are no references to missing `about.html`, `products.html`, `technology.html`, or `contact.html` files.
