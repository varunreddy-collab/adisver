# Paushtika Website

## Project structure

- `index.html` — main Paushtika website and integrated Workshop view.
- `workshop.html` — standalone Workshop page.
- `dashboard-demo.html` — interactive dashboard demo opened from the main page.
- `css/workshop.css` — standalone Workshop styles.
- `js/workshop.js` — standalone Workshop interactions.
- `assets/images/` — Paushtika and shared image assets.
- `assets/images/workshop/` — Workshop-specific images.
- `assets/videos/` — Paushtika video assets.
- `docs/` — project documentation.

All asset paths use the organized directory structure. Timestamped and duplicate-style filenames were normalized without changing the website's intended behavior.
